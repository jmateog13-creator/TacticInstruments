# PROMPTS SPRITES — NANOBANA PIXEL ART
**Estilo:** Pixel art medieval fantástico, 32x32 píxeles, caballeros con armas sonoras
**Transparencia:** Sí, fondo transparente PNG
**Paletas:** Cada familia tiene colores base, sobre eso se aplican 2 variantes de equipo (Azul/Rojo)

## 🎨 INSTRUCCIONES GENERALES PARA NANOBANA:

1. **Resolver cada prompt individualmente**
2. **Tamaño obligatorio:** 32x32 pixels
3. **Fondo:** Transparente (alpha=0)
4. **Escala:** Cada pixel nítido, sin antialiasing
5. **Colores:** Usar paletas exactas indicadas
6. **Contorno:** 1-2 pixels de negro o color oscuro para definición
7. **Detalles:** Máximo 2-3 colores por sprite (base, secundario, brillo)
8. **Posturas:** De pie, arm lista, sin animación (luego se anima en juego)
9. **Exportar:** PNG con nombre `instrumento.png` (ej: `Violín.png`)
10. **Consistencia:** Misma altura de sprite, ancho variable según arma

---

## 🔄 VARIANTES POR EQUIPO:

Para cada sprite, generar **2 versiones**:
- **Equipo 1:** Color secundario = tono AZUL (azul, cyan, turquesa)
- **Equipo 2:** Color secundario = tono ROJO (rojo, rosa, magenta)

Los sprites base (color familia) se mantienen idénticos. Solo cambia el **color secundario** (detalles del casco, ropeta, arma).

---

**Ejemplo de implementación en Canvas:**

```javascript
function drawSprite(ctx, instrumento, equipo, x, y, size=32) {
  const spriteData = SPRITES[instrumento];
  if (!spriteData) return;

  const colors = {
    base: spriteData.colors[0],      // color familia
    sec:   equipo===0 ? spriteData.colors[1] : alterToRed(spriteData.colors[1]),
  };

  // Dibujar según weapon type
  switch(spriteData.weapon) {
    case 'sword':   drawSwordWarrior(ctx, colors, x,y,size); break;
    case 'spear':   drawSpearMan(ctx, colors, x,y,size); break;
    case 'mace':    drawMaceWarrior(ctx, colors, x,y,size); break;
    case 'wand':    drawArcaneMage(ctx, colors, x,y,size); break;
  }
}
```
